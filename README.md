# Matplotlib Visualizations

### Python | Matplotlib | Data Visualization

A collection of Python scripts demonstrating different types of data visualizations using Matplotlib. This repository includes examples of statistical and graphical plots to practice data visualization techniques and understand how to represent data effectively.

---

## About

Matplotlib is a Python library used to create static, animated, and interactive visualizations.

This repository contains individual Python scripts for creating different plot types, along with screenshots of the generated visualizations.

## Visualizations Included

| Visualization | Python File       | Description                                        |
| ------------- | ----------------- | -------------------------------------------------- |
| Bar Chart     | `Bar_Chart.py`    | Compares values across categories using bars       |
| Box Plot      | `Box_Plot.py`     | Displays data distribution and spread              |
| Histogram     | `Histogram.py`    | Shows the frequency distribution of numerical data |
| Pie Chart     | `Pie_Chart.py`    | Represents proportions across categories           |
| Scatter Plot  | `Scatter_Plot.py` | Illustrates relationships between two variables    |
| Stack Plot    | `Stack_Plot.py`   | Displays cumulative data across categories         |
| Stem Plot     | `Stem_Plot.py`    | Represents data points using vertical stems        |
| Step Plot     | `Step_Plot.py`    | Displays data using a step-shaped line             |

## Getting Started

### Install Matplotlib

```bash
pip install matplotlib
```

If your scripts use NumPy, install it as well:

```bash
pip install numpy
```

### Run a Visualization

Run any Python script from the project directory:

```bash
python Bar_Chart.py
```

Replace `Bar_Chart.py` with the filename of the visualization you want to execute.
